# LensShift

**להחליף עדשה, לראות אחרת.** אותו אתגר, שש דרכים להסתכל עליו.

אפליקציית אינטרנט בעברית שמאפשרת לקחת אתגר ולחקור אותו דרך שש עדשות: עובדות, רגש, זהירות, תועלת, יצירתיות ותהליך. בכל עדשה יש שאלות מנחות, ובסוף סיכום שאפשר להדפיס או לשמור כ-PDF.

האתגרים נשמרים בדפדפן של המשתמש/ת.

## קרדיט

שש העדשות מבוססות על שיטת "ששת כובעי החשיבה" (Six Thinking Hats) של ד"ר אדוארד דה בונו (Edward de Bono).

## הרצה מקומית

אפליקציה סטטית בלי שלב build. מספיק להגיש את התיקייה בשרת סטטי, למשל:

```
npx http-server . -p 5173
```

## פרסום

Firebase Hosting, פרויקט `lensshift-1251e`:

```
npx firebase-tools deploy --only hosting --project lensshift-1251e
```
